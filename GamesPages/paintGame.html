What I Learned:

For a long time, this was the project I was most proud of. I made it entirely in one weekend, and all of the artwork was made using Microsoft Paint. I still have fond memories of watching my friends race eachother to get the fastest time. From this project I learned how to rapidly prototype and develop a rough draft of a project. Although this one was never really meant to leave that stage, I still learned a lot about the process from it.
